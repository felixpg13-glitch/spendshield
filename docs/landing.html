AI 开始花真钱了，

当 AI Agent 开始下单、转账、调付费 API——谁给它上闸门？SpendGuard 在「钱该不该动」和「钱怎么动」之间，加一道确定性护栏。

开始使用 → 查看代码
原则

决策由代码，而非 AI 的意见。
规则是确定性的——Agent 无法争辩、欺骗或注入绕过它们。

四道闸门 · 每次花钱全部通过
01

干跑

只预览不执行，直到你放行。

02

预算

硬上限。超支即拒绝。

03

限额

单次上限 + 收款方频率限制。

04

审批

人工确认——终端 / Telegram / Webhook。

黑名单 / 白名单黑名单收款方直接拒绝，白名单信任方跳过确认。v0.2
频率限制同一收款方窗口内最多 N 次——防轰炸式扣款。v0.2
策略即代码所有规则在一个 YAML 文件。可版本化、可评审、可部署。v0.2
MCP ServerClaude Code / OpenClaw 等 MCP 兼容 agent 直接调用护栏。v0.2
远程审批Telegram 或 Webhook 审批——无需终端。v0.3

快速开始
# 包住你的花钱函数
from spendguard import SpendGuard

guard = SpendGuard(budget=200, policy="spendguard.yaml")

@guard.protect("下单")
def place_order(amount, to):
    return call_api(amount, to)

# 默认干跑: 报错提示, 绝不真花
place_order(amount=99, to="麦当劳") # => DryRunBlocked
