为什么 AI 需要付款护栏

Agent 开始持有「信用卡」——Google AP2（Agent Payments Protocol）、Coinbase x402 正在让 agent 自主交易成为标准。

但安全工具缺失：要么闭源、要么绑死单一支付通道、要么根本不存在。

真正难的不是「怎么移动钱」，是「钱该不该动」。——这个决定，应该由确定性的代码做，而不是 AI 的意见。

⚡ 标准成形AP2 / x402 让 agent 自主交易成为确定趋势
🕳 工具真空Python 生态没有像样的支付护栏
🚨 结构性风险Agent 读取不可信内容，可能被诱导花钱
🎯 确定性决策规则由代码执行，Agent 永远无法绕过

快速开始

三行代码，给你的 Agent 上闸门

# 1. 安装
pip install spendguard

# 2. 包住你的花钱函数
from spendguard import SpendGuard
guard = SpendGuard(budget=200, policy="spendguard.yaml")

@guard.protect("下单")
def place_order(amount, to): # 真实下单逻辑
    return call_api(amount, to)

# 3. 干跑模式：报错提示，绝不真花
place_order(amount=99, to="麦当劳") # => DryRunBlocked
